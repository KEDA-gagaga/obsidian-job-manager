# 快速开始

1. 在 Obsidian 设置 → 第三方插件启用「工作投递」。点击左侧公文包。
2. 基础简历填写到 `工作投递/简历/基础工作简历-纯文本版.md`，也可绑定库中其他简历笔记。
3. 新增企业／岗位可以通过 Chrome 采集；预览时核对企业、名称与入口再保存。
4. 收藏的企业在心愿单中，待准备岗位在岗位页。提交网申后才记录已投递。
5. 置顶、备注、归档均可管理，单次操作可撤销；文件有后续编辑时不覆盖新内容。
6. 招聘 Excel 为可选来源。设置中填写表格绝对路径，再点刷新 Excel；原表只读。
7. AI 按钮生成就业日记里的任务。将任务、关联简历与对应模板交给你的 AI 工具执行。

Chrome 连接：打开目标库；使用 Obsidian 1.12.7+ 安装器，在设置 → 常规启用命令行接口，运行下载包的检查连接入口。

安装与升级时请关闭 Obsidian。升级保留数据、简历、笔记与已有模板。新模板变化另见 GitHub 版本说明。
