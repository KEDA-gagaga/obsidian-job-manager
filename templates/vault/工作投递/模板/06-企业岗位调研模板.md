# 企业岗位调研与截图导入模板

核实官方投递入口，保留来源与日期，不猜测企业归属、岗位、截止日期。企业 ID 从插件数据读取；使用 company 对象的 id 或明确的 name。

```json
{
  "company": {"id": "c-example", "name": "示例企业"},
  "checkedAt": "2026-10-09",
  "applicationUrl": "https://example.org/careers",
  "summary": "",
  "locations": [],
  "unknowns": [],
  "sources": [{"url": "https://example.org/careers", "title": "官方招聘", "evidence": "具体入口依据"}],
  "candidates": [{"name": "示例岗位", "batch": "", "location": "", "url": "https://example.org/careers", "requirements": "", "responsibilities": "", "graduateStatus": "待核实", "status": "待核实", "sources": [{"url": "https://example.org/careers", "evidence": "具体岗位依据"}]}]
}
```

运行安装后的连接程序（路径见插件设置）：

```text
JobManager --import --input result.json --kind ai-research
JobManager --import --input result.json --kind screenshot --screenshot 原图.png --save-jobs
```

Windows 程序名为 JobManager.exe。候选不自动变目标岗位；截图保存需要用户明确提供原图路径。没有具体岗位时 candidates 使用空数组。样例仅说明格式，实际网址、日期、名称与 ID 使用核实结果。
