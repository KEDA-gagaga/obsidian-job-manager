# 岗位文案与网申辅助模板

输入：岗位 ID、绑定简历、岗位要求、网申问题和篇幅要求。只用真实经历，缺少事实列为待补充。先完成可复制文案，用户复核后提交招聘网站。

结果输入：

```json
{"jobId":"j-example","resume":"工作投递/简历/基础工作简历-纯文本版.md","body":"# 可直接使用的文案\n\n已复核的文案\n\n# 事实依据与调整\n\n引用绑定简历中的真实经历。"}
```

程序导入：`JobManager --import --input draft.json --kind job-draft`。完整字段校验以插件的 saveJobDraft 为准；如果输出被拒绝，按报错修正，不绕过事务写业务 JSON。Windows 程序名为 JobManager.exe。
